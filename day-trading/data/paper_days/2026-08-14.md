## Tooling: a blocking bug, found and fixed at 07:19

`day-trading.py rank` died mid-cycle:

```
File "day-trading.py", line 282, in __init__
    (2 * (self.c - self.l) - rng) / rng, 0.0)
ZeroDivisionError: float division by zero
```

**Root cause.** A day whose bars are *all interpolated* leaves a **header-only CSV** in
`data/rh_bars` — `DAAQ_2026-08-13.csv`, written by **Day 8's own fake-gap names**.
`load_rh_bars` concatenates every cached file for a symbol, and concatenating that empty,
object-dtype frame with a real one silently coerces **every OHLCV column to `object`**.
`Candles.__init__` guards flat bars with `np.where(rng > 0, ...)`, but on an object array
numpy evaluates both branches in Python, so `high == low` **raises** instead of being
masked.

**Why it matters.** Flat 1-min bars are the norm on illiquid gappers — 5 of 10 candidates
carried them today. And the failure mode is the dangerous one: the ranker does not return
a *wrong* answer, it returns *nothing*, killing the cycle. Day 8's fake-gap detector is
what began leaving the empty CSVs, so the two features interact destructively.

**Fix.** `_coerce_ohlcv()` applied in both `load_rh_bars()` and `_bars_from()`. Forces
numeric dtype, drops unparseable rows, changes no ranking semantics.

## Finding: Trigger C is unusable while FLAT on a 5-minute cadence

Day 8's tooling gap is closed — `trigger` works and fired **all day**: RDDT
bullish_engulfing + tweezer_bottom 07:12, hammer 08:02, bullish_engulfing 08:07,
macd_cross_up 08:49, tweezer_bottom 08:55; BRUN tweezer_bottom 08:04; CGTL
bullish_engulfing 07:10.

**Not one was takeable.** A pattern entry must be sent immediately on the 1-minute close
that produced it; a 5-minute rank cadence means the signal is always 1–5 minutes stale by
the time we see it. Acting anyway is a chase; backfilling is dishonest. So the champion's
third entry trigger is *still* effectively unavailable live — for a different reason than
Day 8, and one that no amount of tooling fixes.

**The sim does not have this problem:** it ranks at the 5-minute mark and then simulates
the ticket forward on **1-minute** bars, so Trigger C fires on a bar that is current.
This is a live-vs-backtest divergence of the same class as the spread veto.

**Fix for the protocol:** once a name is the ranked TOP, poll *its* 1-minute bars every
minute for a buy_set close and act on the next one. The scan economy's "no ranking while
in a position" governs **ranking**, not watching the armed name.

## Ops

* **Session opened 07:12** — 07:00–07:12 logged as a coverage gap, **no backfilled picks**,
  ranking not reconstructed. RDDT's 07:12 Trigger C was deliberately left on the table.
* **`TZ=America/New_York` returned UTC** (no tzdata on this box). The first tick clock was
  an hour wrong and was caught within three minutes by cross-checking against the bar
  timestamps. Rearmed on explicit `UTC−4` arithmetic. *Never trust a named timezone here.*
* **`paper_watch` was reaped twice** (~10:36–10:41 and ~11:33–11:41) as a background
  daemon. **No impact on the record**: state persists in `data/paper/position.json` and
  every 1-min bar is replayed from `data/rh_bars` on each invocation, so nothing went
  unevaluated — the gap was in *notification*, not evaluation. Permanent fix: run it as a
  **foreground one-shot per cycle**, which is what its own docstring prescribes. Running
  it as a daemon was my error and it re-introduced the Day-2 timer-stall failure mode.
* **Zero API truncations** across ~45 batched `get_equity_historicals` calls. The ingest
  assert did fire once — a **false alarm of my own making** (fetched 10 symbols, ranked
  11). Fixed with an explicit `--fetched` list, because *a permanent false alarm trains
  you to ignore the real thing.*
* **New helpers**: `plan/paper_cycle.py` (ingest → rank → ledger in one call, prints 4
  lines) and `plan/bars_csv_to_json.py` (feeds `paper_watch` from the authoritative bar
  cache rather than a second unchecked path).
* **Context economy**: single-symbol `get_equity_historicals` returns **inline** (~40k
  chars) and floods context; the same call for 10 symbols exceeds the cap and **spills to
  a file**, which is what we want. Always batch.

## Verdict

**−$136.12 against a $1,541 benchmark, on one ticket of seven.**

Judge the process, not the number. The day did what a one-holder day must do: the
one-position rule plus a 5h26m hold meant **$85,150 of the $100,000 budget never
deployed**, and C37's $1,541/day assumes rotation through several tickets. A single-holder
day cannot reach the benchmark by construction — the same structural point as Day 8 §9.

What is genuinely new today:

1. A **blocking ranker crash** was found and fixed — it would have silently killed cycles
   on every future gapper day.
2. The veto **cost money for the first time** (LPTH), which is a more useful calibration
   data point than three more saves.
3. **Trigger C remains unavailable live**, now for a cadence reason rather than a tooling
   one — and that is the single clearest gap between this implementation and the champion.
4. Day 8's "halal names are always the wide ones" is **not a law** — today's tightest book
   was armable.

Cumulative **−$363.86** over 4 scored days. Judge weeks, not days.
